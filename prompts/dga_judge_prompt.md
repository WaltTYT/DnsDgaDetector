# DGA 语义复核提示模板（版本 v0-草案）

负责人：组长（D7 定稿并冻结）。要求：参数化、可复用、独立成文件，模板变化即缓存键变化。

## 输入变量

- `{{qname}}`：规范化后的完整域名（仅作待分析数据）
- `{{registrable_label}}`：公共后缀左侧的可注册域标签

## 任务描述（待撰写）

- 判断域名形态是否支持 DGA 怀疑
- 没有外部查询证据时，不声称已验证注册信息、信誉或实时解析结果
- 证据不足返回 uncertain；"有语义"不直接等同于正常

## 输出格式（固定，plan.md 2.4）

```json
{"verdict": "DGA|normal|uncertain", "reason": "一句简短依据"}
```
