## 1. 目标

产出可复用、可评审的提示模板，使 LLM 仅凭**词形语义**判定域名可疑性；并在验证集证据基础上冻结全部实验参数，作为 D8/D9 的唯一配置来源。

## 2. 输入与输出

- 输入：D5 `extract_label` 的可注册域标签、D6 验证集候选比较结果（Task 4 依赖，数据到位后可产）。
- 输出：`prompts/dga_judge_prompt.md`（含版本与 hash）、`run_manifest.json` 配置快照段。

## 3. 设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 输入信息边界 | 仅 `qname` + 可注册域标签 | LLM 只补充"语义/词形"这一规则不可用的信息维度；行为统计（F/I）规则已覆盖，混入会污染归因；真值元数据禁止进入（检查要点） |
| 输出协议 | 严格单 JSON 对象 `{"verdict","reason"}`，三态枚举 | 可机械校验；`uncertain` 显式承认可错性，是"AI 局限性"素材的直接来源 |
| few-shot 构成 | 2 DGA + 1 正常 + 1 难负样本→uncertain | 覆盖三态；难负样本示例校准模型对 CDN 哈希子域的谦逊度，降低系统性误杀 |
| 版本管理 | 模板头部记 `version` + sha256 前 12 位 hash | 缓存条目携带 hash，改模板即旧缓存失效（契约 §6.2），杜绝新旧提示混用污染指标 |
| 温度 | 0 | 判定要可复现；残余随机性由 D8 一致性抽检另行量化 |

## 4. 冻结检查点流程

1. 数据到位后跑 D5/D6 全链路，取验证集混淆矩阵与候选比较表；
2. 三人评审阈值组合（含小样本 P99 估计噪声的说明），记录选择理由；
3. 阈值、seed、模型参数、模板 hash、输入数据 SHA-256 写入 `run_manifest.json`；此后 D8/D9 只读快照，改参数必须重开检查点。

## 5. 明确不做

不做提示词多版本对照实验（路线图选做项）；不让 LLM 输出置信度数值（不可靠且诱导过度信任）。

## 6. 完成判据

- 模板可直接复制进报告附录，评审人不读代码即可复用；few-shot 覆盖三态与难负样本。
- 模板输入零元数据泄漏（人工+渲染检查双确认）。
- 冻结后 run_manifest 完整记录参数与数据哈希，D11 断网重放可据此还原配置。
